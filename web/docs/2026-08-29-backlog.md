## 1. face / banner / addonlist.txt 独立成容器

**现状**：`face.html`、`banner.html`、`战役模式玩特感.html` 在 `web/src/static/html/`，由游戏内 `motd.txt`/`host.txt` 指向。face.html 硬编码了备案号、公安备案号、站点 title；addonlist.txt 的 iframe 已被注释，文件不存在。

**结论**：不独立成容器。纯静态页 nginx 已 serve 良好，独立容器只增复杂度。真正的痛点是「硬编码配置」，改用轻方案：

- 硬编码备案号/title → PHP 渲染读 `.env`（`BRAND_*`），或部署时 `envsubst` 模板替换。
- addonlist.txt 动态生成（列出当前 addons）→ task-daemon 已挂载 addons 卷，由它生成即可。

## 2. COS 下载链接：登录门槛 + 私有桶签名直链

**现状**：`map_info.php` 已有「腾讯CDN（直链下载）」按钮，读 `maps.cos_url`。但 COS 桶已调整为**私有读写**，公开的 `cos_url` 直链已**失效**（无签名访问返回 403）。

**目标**：已登录用户获取地图对应的 COS **单次有效签名直链**，加速下载（国内访问不了创意工坊）；未登录不提供。

**方案要点**：

- 登录校验：`check_login()`，未登录只给 SteamCDN 或提示登录。
- 签名直链：COS 私有桶需生成预签名 URL。当前 [cos.php](../lib/cos.php) 用原生 HMAC-SHA1（AWS S3 V2 兼容）实现上传，需补一个「生成签名 URL」的函数（在 URL 上附加签名 + 过期时间参数）。
- 「单次有效」：COS 预签名 URL 本质是「时效有效」（`X-Expire` 秒内有效），严格单次需另配 CDN 鉴权；可先用短时效（如 60s）近似单次。
- 前端：`map_info.php` 与 `billboard.php` 列表页入口对齐——登录才请求/展示 COS 链接。

## 4. steamcmd 创意工坊订阅替代 steamworkshopdownloader

**背景**：现整个地图元数据 + 下载都依赖第三方 `steamworkshopdownloader.io`（[steam.php](../lib/steam.php)）。该服务 2 年仅 1 次故障（约 1 个月），当时做过 steamcmd 备选方案，后因迁移到网站方案而丢弃。定位为「保险」，非紧迫。

**架构约束（关键）**：

- steamcmd 在**宿主机** `/home/steam/Steam/`（glibc/Ubuntu，见 [l4d2.sh](../../l4d2.sh)），且 L4D2 server appid = 222860。
- task-daemon 容器是 `php:8.3-cli-alpine`（musl），**跑不了 glibc 的 steamcmd**。需解决「容器如何触发宿主机 steamcmd」：

| 方案 | 说明 |
|------|------|
| task-daemon 换 glibc 镜像 | 如 `php:8.3-cli`（debian），挂宿主机 Steam 目录 + addons 卷 |
| 新增 workshop 下载容器 | ubuntu + steamcmd + 挂 Steam + addons 卷，task-daemon 只做编排 |
| 复用 l4d2 容器 | ubuntu:22.04，挂 Steam + addons，但混入下载职责 |

**其他技术点**：

- workshop 下载：`steamcmd +login anonymous +workshop_download_item 550 <id>`。注意 workshop appid = **550**（客户端），非 222860。
- 磁盘布局：steamcmd 下载到 `steamapps/workshop/content/550/<id>/`，需搬运/重命名到 `addons/workshop/<disk_safe>.vpk`。
- 元数据/版本号：Steam Web API `GetPublishedFileDetails`（`time_updated` 作 version，需 Web API key）；或「元数据仍走 steamworkshopdownloader、下载走 steamcmd」的混合方案，先降低改动面。

**建议**：先做技术验证 spike（匿名登录 + 下载一张图 + 确认文件布局 + GetPublishedFileDetails 取版本），再定架构。
